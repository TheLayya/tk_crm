# lay artwork

Copied from the approved original lay4flow-remote anime character assets and SVG animation.
Source repository: `仅远程有头打码/frontend/src/assets/`. The original MIT copyright and permission notice are included in this directory's `LICENSE` and `NOTICE`.

The pink-haired, teal-eyed studio assistant and sakura-room background are existing generated artwork. `KoharuScene.vue` uses the original SVG rig and local `/lay/` layers for greeting, blinking and hair motion. No network service is used to display or animate these assets.

- `koharu-avatar.webp`: brand portrait
- `koharu-login.webp`: standalone login illustration
- `koharu-login-background.webp`: character-free studio background
- `koharu-character.webp`: full character and reduced-motion fallback
- `koharu-motion-*.webp`: segmented character artwork in the original 772 × 1680 coordinate system
- `koharu-wave-displacement.png`: original continuous forearm-wave displacement field
- `koharu-banner.webp`: welcome banner
