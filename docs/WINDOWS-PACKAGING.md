- 总览记录：8 台手机、8 个节点、47 个运营账号、278 个邮箱。
- 同步是一次性快照，不是两个实例自动同步。
- 此 Docker 基线仅用于开发验收，不代表最终安装包依赖 Docker。

启动：

```powershell
docker compose -p tk-crm-local -f docker-compose.local.yml up -d --build --wait
```

停止（数据保留）：

```powershell
docker compose -p tk-crm-local -f docker-compose.local.yml down
```

## UI 验收边界

- 系统 DPI 与 WebView 页面缩放分别处理，不以固定物理像素尺寸假设可用空间。
- 不承诺最小窗口 1180×720 在 1366×768、125% 缩放的屏幕上能放下；窗口必须受实际工作区约束。
- 密集表格允许区域内横向滚动，不能让整个页面溢出。
- 登录画面等比缩放，表单不参与透视变形。
- 100%、125%、150%、200% DPI；1366×768、1920×1080；最大化及缩小窗口均需验收。
- 对未实际测试的组合明确标注未验证，不提前写“正常”。
- 可重复登录布局检查：安装 Playwright 后执行 node desktop/tests/ui-layout.cjs；TKCRM_UI_URL 指向待验收实例，PLAYWRIGHT_MODULE 可指定已有 Playwright 模块目录。不将 CSS 视口模拟当作真实系统 DPI 验收。
