# 数据总览

入口：侧栏或移动端「总览」，页面 `/overview`，只读接口 `GET /api/overview`。

## 权限与范围

需要同时拥有终端、运营账号和代理节点查看权限。遵循已有 all / dept / self 数据范围；共享节点按 ID 去重。返回白名单字段，不返回密码、2FA 或节点凭据。邮箱使用既有 email:view / op_account:view 兼容规则。

## 当前资产快照

- 手机、电脑数量及所属人分布，设备归属人与账号运营人分别展示。
- 未删除终端的当前节点、账号关联；账号状态、粉丝、视频数和最近采集时间。
- 未绑定有效终端的账号、未关联可见终端或账号的节点单列。
- 未采集、超过 7 天未采集、节点过期/7 天内到期、最近测试失败以及采购金额缺失提示。
- 设备没有独立运行状态字段，不推断在线/离线；节点测试结果不是实时状态。

## 金额口径

金额来自当前可见运营账号、节点、邮箱记录的采购价、出售价，使用 Decimal 汇总，并按资产类型、采购渠道和客户拆分。不含设备采购、重复节点续费、卡密及其他运营费用；未录入金额保留缺失提醒，明确录入的 0 与未知不等价。

包括当前记录中的已售资产。更改或删除资产会改变金额，所以这些金额不是历史总支出、实际现金收入或净利润。第一版不提供无法可靠计算的时间趋势、利润或出售人收入分摊。需要历史经营统计时，再引入独立收支流水及更正记录。

账号与节点管理页已移除顶部统计面板及自动统计请求；原统计 API 暂留兼容，业务采购/出售信息未删除。

## 日期筛选与紧凑布局

资产与状态、待处理与数据质量并排展示当前快照，不随财务日期筛选变化。金额、采购渠道和出售客户三块共享「全部 / 今天 / 本周 / 本月 / 自定义」日期范围；快捷范围使用浏览器本地日历，本周从周一开始，本月从一号开始，截止今天。自定义可查看任意日、周、月。

接口接受 date_from / date_to（YYYY-MM-DD），范围包含起止日。采购使用 purchase_date，出售使用 sale_date，各自独立筛选；记录数只统计对应日期范围内已录入金额的记录。0 金额仍算已录入。没有业务日期的金额只在「全部」纳入，并单独提示缺失数量；节点目前没有 sale_date，所以节点出售金额不能按日期归属，不使用创建/更新时间代替。

这仍是按业务日期筛选当前资产记录，不是历史收支流水或历史资产状态。
