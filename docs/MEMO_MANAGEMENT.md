# 备忘管理

统一入口 `/work-items`，SSH 信息、采购渠道和团队任务都记录在同一张清单中，不拆分类模块。

- 只有大类、标题、内容、提醒成员和提醒时间；提醒可不填。
- 新建时选择管理员预设的大类：采购渠道、VPS续费、未结款项、团队任务、账号/节点、其他；成员不自由填写，避免同义词导致筛选失效。
- 拥有 `settings:edit` 权限的管理员可通过“大类设置”维护选项，每行一个；必须保留“其他”，已有备忘使用的大类不能直接删除。
- 提醒成员可选“全员”，所有拥有备忘查看权限的成员均会收到提醒，包括后续新增的成员，无需逐个选择。
- 点击标题原地展开内容，支持编辑、完成、恢复和删除。
- 默认隐藏已完成记录，支持搜索标题/内容及筛选提醒自己的备忘。
- 内容在数据库中加密保存；拥有查看权限的成员可查看全部共享备忘，请只授权可信成员。
- 提醒时间按浏览器本地时间输入，统一转换为 UTC 保存。
- 登录并保持网页打开时，每分钟检查到期提醒；顶部铃铛显示到期数量，点击进入备忘清单。
- 当前没有离线推送、短信、邮件或 Telegram 通知。

角色权限：`work_item:view` 查看备忘，`work_item:manage` 新增、编辑、完成和删除。超级管理员自动拥有权限，普通成员需在角色管理中授权后重新登录。

更新后重启后端以注册接口和创建新表；部署时执行 `alembic upgrade head`。
